# [DoomMake Project]

by Generic Doom Guy

## What This Is

This is a repository containing a work in progress mapset using [chex3d2.wad](https://www.chexquest.org/index.php?topic=5977.0) as the iwad. The goal is to make dumb but fun mini slaughter maps while teaching myself basic/intermediate mapping techniques, decohack to diversify/toughen the bestiary of Chex Quest 3 and to actually learn how to maintain a repository on github lol

You are more than welcome to use any decohack or dehacked files in here as long as I am credited. I do recommend you wait till a full release is available as this is the very beginnings.

Tools being used:
- [Doomtools](https://github.com/MTrop/DoomTools)
-- excellent suite of CLI based tools for doom that even comes with a gui
- [Slade](https://slade.mancubus.net/) 
-- main map editor as of 2026/05/31
- [Ultimate Doom Builder](https://ultimatedoombuilder.github.io/)
-- not used for mapping yet but was successfully compiled by me 2026/05/30 on [Zorin OS](https://zorin.com/) per Github instructions and will most likely be used
- [DSDA-Doom](https://github.com/kraflab/dsda-doom) & [Woof!](https://github.com/fabiangreffrath/woof)
-- source ports used for testing
